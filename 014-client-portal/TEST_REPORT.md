## 7. 開発中に見つけて修正した不具合
1. 部分更新（PATCH）で送っていない項目が既定値（空文字等）で上書きされる（zod の partial と default の組合せ）→ `patchSchema` で修正、回帰テスト追加。
2. 本番ビルド時にマイグレーション/サンプル画像のパス解決が誤る → 候補パス修正、本番モード起動で確認。
3. オフライン状態でポータルを開くと「ページを開けません」のまま → 通信エラー時の文言と再接続時の自動再読込を追加（運営者画面も同様）。
