# OPERATING_COSTS — 運用費の試算方法

- 調査日: **2026-09-29**。料金は変わるため、契約前に必ず各社の公式料金ページで再確認してください。
- 出典の確度:
  - **[公式確認]** 公式の料金データ（AWS Price List API）または公式ドキュメントのソースリポジトリ（Fly.io / Cloudflare）で確認
  - **[未検証]** 公式ページを直接開けず（開発環境の通信制限）、検索結果の要約のみ。**販売・契約前に人間がブラウザで確認が必要**
- 料金・単価はアプリのコードに埋め込んでいません。アプリ側で変えられるのは容量上限などの設定値（環境変数 `MAX_UPLOAD_MB`, `MAX_PROJECT_STORAGE_MB`, `MAX_ACTIVE_PROJECTS`, `MAX_ZIP_MB` 等）のみです。
- 税・為替は含みません（USD表記はドル建て）。

## 1. 主要コストの構造

| 費目 | 何で増えるか | 備考 |
|---|---|---|
| サーバー（計算資源） | 常時1台 | 1〜数人の運営者なら最小〜1GBメモリで足りる想定（負荷試験結果は TEST_REPORT.md） |
| ディスク（SQLite + ファイル） | 保存容量 | ファイルをローカル保存する場合は容量に比例 |
| オブジェクトストレージ | 保存容量・リクエスト数 | ファイルを R2/S3 に置く場合 |
| 転送量（egress） | 顧客のプレビュー・ダウンロード量 | **最も読みにくい費目**。動画・大容量納品が多いと増える |
| バックアップ保管 | バックアップ容量 × 世代数 | ファイルも含めて複製するため保存容量の数倍になりうる |
| メール（任意） | 通知・招待メール数 | 使わなければ0（招待リンクは手動送付で運用可能） |

## 3. 試算の手順（自分の数字に置き換えて計算）

```
月額 ≒ サーバー
      + 保存容量(GB) × ストレージ単価
      + バックアップ容量(GB) × 世代数 × バックアップ保管単価
      + 月間ダウンロード量(GB) × 転送単価
      + (メール通数 / 1000) × メール単価
```

月間ダウンロード量の目安 = 納品・確認のファイル容量 × 顧客が見る回数（プレビュー含め 2〜5 回程度を想定）。

## 4. 試算例（計算方法の例示。保証値ではありません）

前提: 構成A = Fly.io 東京 1GB + Volume にファイルも保存。構成B = Fly.io 東京 512MB + ファイルは R2。
ダウンロード量 = 保存容量 × 3 と仮定。バックアップは Fly のスナップショットのみ（構成A）/ R2 は同一バケット外へのアプリ側バックアップ1世代（構成B）。

### ケース1: 1案件あたり 1GB × 月1案件（保存 1GB、DL 3GB）
- 構成A: 7.45 + 3GB確保×0.15(=0.45) + スナップショット(10GB以内 0) + 3×0.04(=0.12) ≒ **$8.0/月**
- 構成B: 4.18 + Volume 1GB×0.15(=0.15) + R2(10GB以内 0) + 転送0 ≒ **$4.3/月**

### ケース2: 保存 10GB（DL 30GB/月）
- 構成A: 7.45 + 15GB確保×0.15(=2.25) + スナップショット(10GB超過分 数GB×0.08 ≒ 0〜0.4) + 30×0.04(=1.2) ≒ **$11〜11.5/月**
- 構成B: 4.18 + 0.15 + R2 保存(10GB 無料枠内 0) + バックアップ用 10GB×0.015(=0.15) + 転送0 ≒ **$4.5/月**

### ケース3: 保存 100GB（DL 300GB/月、動画中心）
- 構成A: 7.45 + 120GB確保×0.15(=18) + スナップショット(~90GB×0.08=7.2) + 300×0.04(=12) ≒ **$45/月**
- 構成B: 4.18 + 0.15 + R2 90GB×0.015(=1.35) + バックアップ 100GB×0.015(=1.5) + リクエスト（通常は無料枠内）+ 転送0 ≒ **$7.2/月**
- 参考: 同じ条件で S3 東京に置くと 保存 100×0.025=2.5 + 転送 (300−100)×0.114=22.8 ≒ $25 + サーバー

→ **ファイル容量・ダウンロードが多いほど、R2（転送無料）へ切り替える効果が大きい**。10GB程度まではディスク保存でも十分。

### 国内VPS（Docker）の場合
- 月額 約1,000〜2,000円（未検証）＋バックアップ先（外部ストレージやスナップショットは別料金のことが多い）。転送量無制限のプランが多いが、ディスク容量（例: 100GB）が上限になる。

## 5. コストを抑える設定
- `MAX_UPLOAD_MB`（既定500MB）、`MAX_PROJECT_STORAGE_MB`（既定0=無制限）、`MAX_ZIP_MB`（既定4096MB）で上限を設定。
- 完了した案件は「アーカイブ」、不要になった案件は「削除」（ファイル実体も削除）。
- 動画は提出前に圧縮・長さを確認（プレビュー時の転送量が大きい）。
- バックアップの世代数を決め、古いバックアップを削除（OPERATIONS.md）。
