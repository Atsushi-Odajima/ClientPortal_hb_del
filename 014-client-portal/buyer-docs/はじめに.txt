Client Portal — 顧客専用ページ・ファイル受け渡し・確認承認
はじめに（最初にお読みください）
==================================================

■ このアプリでできること
クライアントごとに専用ページを作り、必要資料の回収、制作物の提出、修正コメント、OK承認、最終納品までを1か所にまとめられます。
メール・LINE・Slack・DMに散らばりがちな「資料・修正・承認・納品」を案件ごとに整理し、
「最新版はどれ？」「どこを直す？」「本当にOKをもらった？」「納品物はどこ？」をなくします。

  - 運営者（あなた）: パソコン・スマホで案件、顧客、資料依頼、制作物（v1/v2/v3…）、承認、納品を管理
  - 顧客（お客様）: 招待リンクから開き、スマホでも資料提出・確認・画像へのピンコメント・修正依頼・承認・納品受け取り

見積・請求・入金管理の機能はありません（別商品の範囲です）。

■ 必要なもの
  - このアプリを置くサーバー（下記のどちらか）
      A. Fly.io（東京リージョン）… 推奨。クレジットカード登録が必要
      B. 国内VPS（さくらのVPS、ConoHa VPS 等）+ Docker
  - 独自ドメイン（任意。なくても Fly.io なら https://<名前>.fly.dev で使えます）
  - 月額費用の目安は「OPERATING_COSTS.md」（サーバー代＋保存容量＋転送量）
  ※ サーバーの契約・支払いはご自身のアカウントで行ってください。販売者側では契約・公開を行っていません。

■ 導入手順（A: Fly.io の場合・約30分）
  1. https://fly.io でアカウントを作成し、flyctl（コマンドツール）をインストール
  2. このフォルダ（014-client-portal）で次を順に実行
       fly launch --no-deploy --copy-config --name <好きなアプリ名> --region nrt
       fly volumes create portal_data --region nrt --size 3
       fly secrets set SESSION_SECRET=<ランダムな長い文字列> SETUP_TOKEN=<自分で決める合言葉> PUBLIC_URL=https://<アプリ名>.fly.dev
       fly deploy
     ※ ランダムな文字列は、パソコンのターミナルで openssl rand -hex 32 を実行すると作れます。
  3. ブラウザで https://<アプリ名>.fly.dev を開く →「初期設定」画面で
     セットアップ用トークン（SETUP_TOKEN）、氏名、屋号、メール、パスワードを入力
  4. ログインできたら完了です。

■ 導入手順（B: VPS + Docker の場合）
  1. VPSに Docker をインストールし、ドメインのDNS（Aレコード）をVPSのIPに向ける
  2. このフォルダをVPSにコピーし、.env.example を .env にコピーして
     PUBLIC_URL / SESSION_SECRET / SETUP_TOKEN / DOMAIN を記入
  3. docker compose up -d --build
  4. https://<ドメイン> を開いて「初期設定」
  詳しくは DEVELOPMENT.md「デプロイ」を参照。

■ 最初にやること（5分）
  1. 設定 →「サンプル案件を作成」で、流れを体験（サンプルは後でワンクリック削除できます）
  2. 表示された顧客体験用リンクを、スマホや別のブラウザで開き、お客様側の画面も確認
  3. 設定 → 屋号を確認（お客様の画面に表示されます）
  4. 本番の案件を作成 →「共有・招待」で招待リンクを発行 → お客様へ送付
     （送付文の例は「顧客への案内方法.txt」）

■ 大切なこと
  - バックアップを必ず定期的に取り、サーバーとは別の場所に保管してください（OPERATIONS.md）。
  - 承認機能は制作上の確認記録です。電子契約・電子署名の代わりにはなりません（注意事項.txt）。
  - 資料一覧
      運営者向け使い方.txt / 顧客への案内方法.txt / スマホで使う.txt
      ファイルと承認の仕組み.txt / 注意事項.txt / サンプル案件説明.txt
      ポータルの使い方（お客様向け）.txt … お客様へそのまま渡せる案内
      THIRD_PARTY_NOTICES.txt … 利用しているオープンソースのライセンス
