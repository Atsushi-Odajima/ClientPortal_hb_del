サンプル案件の説明
==================================================

■ 作り方
  運営画面 → 設定 →「サンプル案件を作成」
  （開発者向け: npm run demo で、本番とは別フォルダ data-demo にデモ環境を作って起動することもできます）

■ 内容（すべて架空です）
  顧客: Sample Creative株式会社（担当: 見本 花子 / sample-client@example.com）
  案件: 秋キャンペーンSNS素材制作

  資料依頼
    ロゴデータ（ファイル）… 提出済み → 確認済み
    商品写真（ファイル）… 提出済み → 確認済み
    掲載文（テキスト）… 提出済み → 確認済み
    ブランドカラー（テキスト・任意）… 未提出（お客様側で提出を体験できます）

  制作物
    投稿画像A: v1 提出 → お客様がピンコメント2件（「キャッチコピーを大きく」「ロゴを右下へ」）
               → 修正依頼 → v2 提出 → 承認
    投稿画像B: v1 提出 → 承認

  最終納品: 「最終納品」（投稿画像A v2、投稿画像B v1）を公開済み

■ 体験のしかた
  運営者側: 案件を開き、各タブ（資料・制作物・納品・履歴）を確認。制作物「投稿画像A」の v1（旧版）でピンと修正依頼、
            v2 で承認記録（ハッシュ値）を確認できます。
  お客様側: サンプル作成後に表示されるリンクを、スマホや別ブラウザ（シークレットウィンドウ）で開き、
            メールアドレス sample-client@example.com を入力。「やること」「資料」「確認」「納品」「履歴」を操作できます。

■ 本番との分離
  - 一覧で「サンプル」と表示されます。
  - サンプルではメールは送信されず、期限超過の通知も出ません。
  - 設定 →「サンプルを削除」でサンプル案件・サンプル顧客・ファイルをまとめて削除できます。
